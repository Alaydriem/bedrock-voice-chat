Radial · controls

Squares, because the mark is blocks

The knobs, boxes and dots are all squares with small radii. A pill-shaped toggle in this system reads as borrowed from somewhere else. Two exceptions are deliberate: a radio is round because roundness is what says exactly one, and a range thumb is round because it is a grabbable point.

Buttons

One component, two scales

The prototype grew two complete button systems — a tracked, uppercase one at onboarding scale and a compact one in settings — with the same variant names meaning different things in each. A primary action is a primary action wherever it appears, so they are one component with a size.

Inputs

State lives on the ARIA attribute

aria-checked and aria-pressed are the source of truth rather than a mirror of it, so a control cannot look one way and report another. Everything below is wired by one delegated listener on the page rather than one per control — these appear in lists that get rebuilt, and per-element listeners would leak.

toggle · segmented · select Disabled controls grey out rather than disappear, so the setting stays findable. 
<button class="rad-toggle" role="switch" aria-checked="true"
        data-rad-toggle="noise-gate" aria-label="Noise gate"></button>
