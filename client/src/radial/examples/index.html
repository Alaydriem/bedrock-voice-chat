Radial · BVC design system

One mark, drawn every way the product needs it

The logo is not a badge. It is 137 blocks on a 23×13 grid where every column is one contiguous vertical span — a waveform envelope running violet to red across the spectrum. One drawing routine renders it as a header logo, as a level meter beside a name, and as the ring on the empty state. Every colour in the palette is a column of it.

Mark

The dancing logo

Cell size comes from the --rad-mark-cell custom property, so a container query decides how big the mark is and the TypeScript never learns what a phone is. The violet mortar fills the gaps inside the silhouette only: the blocks read as blocks without the negative space going black and without a panel appearing around the logo.

Ring

The mark, with circles around it

Seventy-two bars, each a radial stack of segments. A voice is placed by angle and pushes the bars near it outward, tinted with that player's hue — which is how the ring says who and where without carrying a single name. It is the empty state and the status oscilloscope, and never a control surface or a roster: identification wants recognition, not recall.

Level meter

A voice, as the mark at low amplitude

Driven by pushed data, never by an internal oscillator: a meter subscribes to a LevelSource and knows nothing else. On these pages the source is synthetic; in the app it is whatever the audio layer hands over. Colour is a hex, or rainbow for the spectrum.

Server glyph

Identity, derived from the name

No upload, no avatar service, no default grey box. A hostname hashes to a hue from a column of the mark and a mirrored 5×5 block pattern, so every server looks distinct, looks like it belongs here, and looks the same on every client that knows its name.

Shell

The frame is the container query root

Every responsive decision in the kit is made against @container rad, never against the viewport. Switching the specimen below between desktop and phone changes one element's width; everything inside re-lays itself out because its container changed. That is also why a component behaves correctly inside a sheet, a sidebar or a 412px window without knowing it is in one.

Icons

No font, no CDN, no request

The client ships offline and runs in a WebView, so an icon that needs a request is an icon that is sometimes missing. Every glyph is stroke-built inline SVG on one 24×24 box at a 1.9 stroke with round caps, sized by its host in em and coloured by currentColor. Swapping data-rad-icon swaps the glyph, which is how a mic becomes a struck-through mic on mute without the button knowing any markup.

<span data-rad-icon="mic"> 
<span data-rad-icon="mic"></span>

const icon = new IconBinding(el);
icon.name = muted ? "micoff" : "mic";
