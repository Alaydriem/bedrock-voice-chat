A component set, not a page count

Settings reuses the dashboard's shell — the same rail, the same second column, now a section list. What matters is the kit: rows, toggles, selects, one dropdown that serves both selects and row actions, tables, chips, callouts, empty states and a confirm. The panes are built out on top of it so the kit gets tested against real content rather than lorem.
