## Does it work on Realms?

Yes, Realms is fully supported via Bedrock Voice Chat Connect. See [Realms](/wiki/platforms/realms/).

## Does it work on Aternos?

Yes, Aternos is fully supported via Bedrock Voice Chat Connect. See [Aternos](/wiki/platforms/aternos/).

## Does it work on a LAN or single-player world?

No. Single Player worlds are not supported. Use a Minecraft Bedrock Realm, Aternos Server, or Bedrock Dedicated Server instead.

## Can I use it on Xbox, PlayStation, or Switch?

Yes, with the mobile app running next to the console. There is no on-console client. [Console and mobile](/wiki/platforms/console-and-mobile/).

## Does it work with Geyser?

Yes. Install the Java mod. Floodgate is auto-detected. [Geyser and Floodgate](/wiki/server/java-mod/integrations/geyser-and-floodgate/).

## Does it work with Simple Voice Chat?

Bedrock Voice Chat provides an interface for both Bedrock and Java players to chat with each other _without_ needing to integrate with Simple Voice Chat. SVC and BVC are two unrelated systems that do not depend on each other.

Install the [Java mod](/wiki/server/java-mod/) and your Java and Bedrock players hear each other through the BVC apps.

## Is there a public server I can join?

No. There is no official server and no directory of them. Any operator can install BVC, and there is no central place to point you at.

If you already play somewhere you like, ask the owner to install it. The [guide](/wiki/server/) is here.

## What is my login URL?

The address of the **BVC server**, not your Minecraft server, Aternos address, or Realm. Your operator sets it up and gives it to you. [Signing in](/wiki/player/signing-in/).

:::danger
Bedrock Voice Chat **will not work** if you put your Aternos Server URL, IP Address, or Bedrock Dedicated Server address in the login field. You **MUST** use the **Bedrock Voice Chat Server** address.
:::

## Do I need the BVC server if I use the Java mod?

Not always. The Java mod can run BVC embedded in your game server. Good for small always-on servers, poor on low-end hosts. [Java mod](/wiki/server/java-mod/).

## Can I record?

Yes, on desktop, with each player on their own track. Not on mobile. Your server operator can turn recording off. [Recording](/wiki/creator/recording/).

## Can I read in-game chat in the app?

Yes. The app mirrors server chat and sends what you type back into the game. [Chat](/wiki/player/chat/).

## Is it free?

Yes. [Supporting the project](/wiki/start/supporting-bvc/) funds development and gets you early access to builds, which matters most around Minecraft updates.

## I updated Minecraft but Bedrock Voice Chat stopped working

New versions of Minecraft often have protocol updates. Mojang does not document the Bedrock packet protocol and changes it every release. The work cannot start until the update ships. [Version support](/wiki/platforms/version-support/).

This issue only affects Realms and Aternos server. To have day one support, run Bedrock Voice Chat alongside Bedrock Dedicated Server
