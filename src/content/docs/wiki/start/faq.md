## Does it work on Realms?

Yes. The BVC app connects to the Realm for you, with a feature called Bedrock Voice Chat Connect. After each Minecraft update, BVC can stop working on Realms until a matching BVC version is available. See [Realms](/wiki/platforms/realms/).

## Does it work on Aternos?

Yes. The BVC app connects to the Aternos server for you, with Bedrock Voice Chat Connect. After each Minecraft update, BVC can stop working on Aternos until a matching BVC version is available. See [Aternos](/wiki/platforms/aternos/).

## Does it work on a LAN or single-player world?

No. Bedrock Voice Chat does not work on LAN worlds or single-player worlds. Use a Realm, an Aternos server or a Bedrock Dedicated Server. See [LAN and local worlds](/wiki/platforms/lan-and-local-worlds/).

## Can I use it on Xbox, PlayStation, or Switch?

Yes. Use the mobile app on a phone or tablet. There is no console app. See [Console and mobile](/wiki/platforms/console-and-mobile/).

## Does it work with Geyser?

Yes. Install the Java mod. The mod detects Floodgate automatically. See [Geyser and Floodgate](/wiki/server/java-mod/integrations/geyser-and-floodgate/).

## Does it work with Simple Voice Chat?

Yes. The BVC Java mod connects to Simple Voice Chat. Java players on Simple Voice Chat and players on the BVC app can then hear each other. See [Simple Voice Chat](/wiki/server/java-mod/integrations/simple-voice-chat/).

You do not need Simple Voice Chat. With only the [Java mod](/wiki/server/java-mod/), your Java and Bedrock players hear each other through the BVC app.

## Is there a public server I can join?

No. There is no official server and no list of servers.

If you already play on a server that you like, ask the owner to install BVC. Send them [Running a server](/wiki/server/).

## What is my server URL?

Use the address of the BVC server. Your server operator sets up the BVC server and gives you the address. See [Signing in](/wiki/player/signing-in/).

:::danger
Bedrock Voice Chat **will not work** if you enter your Aternos server address, an IP address, or your Bedrock Dedicated Server address in the server URL field. You **MUST** use the address of the **Bedrock Voice Chat server**.
:::

## Do I need the BVC server if I use the Java mod?

Not always. The Java mod can run the BVC server inside your Minecraft server. Use this on small servers that are always on. Do not use it on low-end hosts. See [Java mod](/wiki/server/java-mod/).

## Can I record?

Yes, on desktop. Each player records to a separate track. Mobile devices cannot record. Your server operator can turn off recording. See [Recording](/wiki/creator/recording/).

## Can I read in-game chat in the app?

Yes. The app shows the server's chat, and sends your messages into the game. See [Chat](/wiki/player/chat/).

## Is it free?

Yes. [Supporting the project](/wiki/start/supporting-bvc/) funds development. Supporters get early access to new builds. This is most useful after a Minecraft update.

## I updated Minecraft and Bedrock Voice Chat stopped working

On Realms and Aternos, Bedrock Voice Chat can stop working after a Minecraft update. Each update can change the Bedrock network protocol, and BVC must be updated to match. Mojang does not document this protocol. The BVC developers can start this work only after Mojang releases the update. See [Version support](/wiki/platforms/version-support/).

A Bedrock Dedicated Server is not affected. Use one to keep voice chat working on the day of an update.
